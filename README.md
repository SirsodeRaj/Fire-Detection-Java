# 🔥 Fire Detection Java System

A Java-based Fire Detection and Alert Management System designed to monitor fire incidents, manage records, and provide alert handling through a desktop application interface.

## 📌 Features

- 🔐 User Login Authentication
- 🔥 Fire Detection Management
- 📜 Fire Incident History Tracking
- 📧 Mail Data Handling / Alert Notifications
- 🗄️ Database Connectivity
- 🖥️ Java GUI-based Application
- 📂 Record Management System

---

## 🛠️ Technologies Used

- Java
- Java Swing / AWT
- JDBC
- MySQL Database
- OOP Concepts

## ⚙️ Setup Instructions

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/SirsodeRaj/Fire-Detection-Java.git
```

### 2️⃣ Open Project

Open the project in any Java IDE:

- IntelliJ IDEA
- Eclipse
- NetBeans
- VS Code

---

### 3️⃣ Configure Database

- Create a MySQL database.
- Open:

```bash
fire database query.txt
```

- Execute the SQL queries in MySQL Workbench or phpMyAdmin.

---

### 4️⃣ Add JDBC Driver

Make sure MySQL JDBC Connector is added to your project libraries.

Download:
https://dev.mysql.com/downloads/connector/j/

---

### 5️⃣ Run the Application

Run:

```bash
mainapp.java
```

or run the login screen first:

```bash
login.java
```
